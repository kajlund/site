# Site

Root website built using Node.js/Express with Nunjucks templating and webcomponents. Deployed at [kajlund.com](https://kajlund.com).

- Landing page with random quotes from [proverbs app](https://proverbs.kajlund.com)
- Blog link to [blog](https://blog.kajlund.com)
- Demos page. List of deployed demos.
- About page.
- Login dialog setting cookie to work througout the domain and sub-domains.
